# AI Interview Cheat Sheet

A single-page AI / LLM interview cheat sheet: theory, quick references and interview Q&A, from foundations to advanced systems.

**Live site:** https://deven1003.github.io/AI_cheat_sheet/

## What's inside

| Section | Topics |
|---|---|
| **Foundations** | AI vs. ML vs. Deep Learning vs. Gen AI, models, tokens and tokenization, training vs. inference, learning paradigms, overfitting, knowledge cutoff |
| **Core Concepts** | Neural networks, embeddings, transformers and attention, LLMs, context window, prompt engineering, sampling (temperature, top-k, top-p), fine-tuning, RAG, hallucination, evaluation metrics |
| **Advanced & Systems** | RLHF and alignment, PEFT / LoRA / quantization, AI agents and tool use, Model Context Protocol (MCP), multimodal models, Mixture of Experts, inference optimization, guardrails and prompt-injection safety |
| **Side-by-Side** | Comparisons of commonly confused concepts |
| **On the Job** | How these ideas show up in real interviews and real work |

## Run locally

It's a single static file, so no build step is needed:

```sh
git clone https://github.com/deven1003/AI_cheat_sheet.git
cd AI_cheat_sheet
# open index.html in your browser
```
